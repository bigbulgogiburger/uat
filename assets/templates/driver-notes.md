# 드라이버 메모 — <프로젝트> (<기기/브라우저> · 회차 간 이어짐: carry_work 에 넣는다)

> 레인이 화면을 조작하다가 알게 된 **이 앱에서만 통하는 요령**을 적는다. 다음 회차 레인이 같은 시행착오를 반복하지 않게 하려는 것이다.
> 결함은 여기 쓰지 않는다(verdict.py). 비밀 값도 쓰지 않는다.

## 입력
- <예) 주소 검색 칸은 탭 후 0.5초 기다려야 포커스가 잡힌다 · 숫자 키패드 칸은 `type` 대신 `secret_type --digits`>

## 이동·대기
- <예) 결제 결과 화면은 「확인」이 화면 밖 — `swipe up` 한 번 · 목록 첫 로딩은 `wait "주문 내역" --timeout 20`>

## 상태 만들기
- <예) 「배송 중」은 상태 시드 도구 `set <번호> shipping` · 빈 계정은 계정#3>

## 기기 설정 (회차 정리 때 원복)
- <예) 키보드 앱 끔(붙여넣기 메뉴를 가림) — 정리 때 다시 켬 · 글자 크기 · 회전>
